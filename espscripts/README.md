# ESPScripts

Dit ESPHome-værksted i Home Assistant. Gem og genbrug YAML med grafik, boards, sensorer, testnoter og versionshistorik.

Indbygget katalog med 211 boards og 200 sensorkomponenter, egne hardwaretilføjelser og Standardprint til COMMON, WireGuard og hardware.

Åbn appen fra sidepanelet efter installation. Se fanen Dokumentation for opsætning og backup.

Tilføj hardware ved at indsætte et produktlink. Kontrollér forslaget, vælg hardwaretype, og gem modellen i dit lokale katalog.
